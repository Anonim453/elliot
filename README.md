# 🎙️ Elliot — Голосовой ИИ-помощник для Windows

Современный десктопный голосовой ассистент на Python и PyQt6, управляющий системой через голосовые команды и диалоговый ИИ.

---

## 🌟 Ключевые возможности

- 🗣️ **Распознавание речи (STT)**: Быстрое локальное распознавание через `faster-whisper` (CTranslate2) без передачи звука сторонним сервисам.
- 🛡️ **Детекция речи (VAD)**: Интеграция `Silero VAD` — мгновенное отсечение шума и тишины, автоматическое определение конца фразы.
- 🧠 **Интеллектуальное ядро (LLM)**: Google Gemini с поддержкой **Function Calling** (вызов системных функций напрямую моделью).
- 🔊 **Синтез речи (TTS)**: Высококачественный естественный голос через Microsoft Edge TTS (`ru-RU-DmitryNeural`) — бесплатно и без API ключей.
- 💻 **Управление Windows (Системные инструменты)**:
  - 🔊 Регулировка громкости системы (`pycaw`)
  - 🚀 Запуск и закрытие любых приложений (Блокнот, Браузер, Калькулятор, Word и др.)
  - 🌐 Открытие сайтов и поиск в Google
  - 📊 Мониторинг ресурсов (загрузка CPU, RAM, диска C:)
  - 🎵 Управление медиа-воспроизведением (Play/Pause, Next, Prev)
  - ⚡ Управление питанием (выключение, перезагрузка, сон, блокировка экрана)
  - 📁 Файловые операции (создание, чтение, удаление)
  - ⏰ Текущее время и дата на русском языке
  - 🖥️ Выполнение PowerShell команд
- 🎨 **Графический интерфейс (GUI)**:
  - Стильный безрамочный дизайн (Fluent / Dark Theme)
  - Неоновая 60 FPS визуализация голосовых волн (Waveform)
  - Анимированные пузыри чата (пользователь, ассистент, плашки инструментов)
  - Индикатор состояния ассистента (Ожидание, Слушаю, Думаю, Отвечаю)
  - Сворачивание в системный трей (System Tray)
  - Глобальная горячая клавиша активации (`Ctrl+Space`)

## 🏗️ Архитектура

```
elliot/
├── assets/                  # Стили, звуки, иконки
│   └── styles/
│       └── dark_theme.qss   # Fluent Dark тема оформления
├── config/                  # Конфигурация приложения
│   ├── settings.py          # Pydantic BaseSettings
│   └── prompts.py           # Системный промпт Elliot
├── core/                    # Ядро ассистента (не зависит от GUI)
│   ├── audio/               # Захват (recorder), плеер (player), VAD
│   ├── stt/                 # faster-whisper STT
│   ├── tts/                 # edge-tts синтез
│   ├── llm/                 # Gemini API клиент + память диалога
│   └── tools/               # Реестр инструментов и системные команды Windows
├── ui/                      # PyQt6 интерфейс
│   ├── widgets/             # Waveform, ChatView, StatusIndicator, TrayIcon
│   ├── workers/             # AssistantWorker (отдельный QThread)
│   ├── controller.py        # Связующий контроллер
│   └── main_window.py       # Главное окно 450x700
├── tests/                   # Набор автоматических тестов
├── .env.example             # Пример конфигурации
├── requirements.txt         # Зависимости
├── main.py                  # Точка входа
└── README.md
```

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/Anonim453/elliot.git
cd elliot
```

### 2. Создание виртуального окружения и установка зависимостей
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Настройка окружения
Скопируйте `.env.example` в `.env`:
```bash
copy .env.example .env
```
Укажите ваш бесплатный ключ Google Gemini в `.env`:
```ini
GEMINI_API_KEY=ваш_ключ_здесь
```
*(Получить ключ бесплатно: [Google AI Studio](https://aistudio.google.com/apikey))*

### 4. Запуск тестов
```bash
python -m pytest tests/ -v
```

### 5. Запуск ассистента
```bash
python main.py
```

## ⌨️ Горячие клавиши

- `Ctrl + Space` — включить / выключить прослушивание микрофона
- `Enter` в строке ввода — отправить текстовый запрос
